# AI Agent Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/YakeruMeio/AI-agent-Qwen/blob/main/Qwen2.5-VL-7B.ipynb)

Локальный AI-агент в Google Colab на базе **Qwen2.5-VL**, **llama.cpp**, **Stable Diffusion** и **Gradio**.

Проект рассчитан на запуск в Colab с GPU, обычно Tesla T4.

---

## Что умеет

- общаться через удобный веб-чат Gradio;
- понимать текст и изображения через Qwen2.5-VL;
- искать информацию в интернете;
- читать веб-страницы;
- писать и выполнять Python-код;
- читать и создавать файлы в рабочей папке;
- генерировать изображения локально через Stable Diffusion;
- работать без Google Drive, если диск не нужен;
- сохранять модели и бинарники на Google Drive, если он подключён.

---

## Быстрый старт

1. Нажмите кнопку **Open in Colab** выше.
2. В Colab выберите GPU:

```text
   Runtime / Среда выполнения → Change runtime type / Сменить среду выполнения → GPU
```

3. Запускайте ячейки по порядку:

```text
   1 → 2 → 3 → 4 → 5 → 6 → 7
```

4. После запуска Ячейки 7 появится публичная ссылка Gradio.
5. Откройте её в браузере и пользуйтесь чатом.

## Основные компоненты

### Qwen2.5-VL

Модель понимает текст и изображения.

Используется через `llama.cpp`.

### llama.cpp

Движок для запуска GGUF-моделей.

В проекте собираются только нужные бинарники:

- `llama-server`
- `llama-cli`

### Stable Diffusion

Используется для локальной генерации изображений.

Модель загружается только при первом запросе на генерацию картинки.

### Gradio

Даёт простой веб-интерфейс с чатом.

Если включён режим:

```python
GRADIO_SHARE = True
```

Gradio сам создаёт временную публичную ссылку.

Отдельный `cloudflared` или `ngrok` для чата не нужен.

## Важные настройки

В начале ячеек есть простые блоки настроек.

### Ячейка 1

```python
DRIVE_ENABLED = True
```

Поставьте:

```python
DRIVE_ENABLED = False
```

если не хотите подключать Google Drive и не хотите видеть окно авторизации.

### Ячейка 4

```bash
CTX_SIZE=8192
```

Это размер контекста модели.

Контекст — сколько текста модель может держать перед глазами за один раз.  
Больше контекст — больше расход памяти.

### Ячейка 7

```python
MAX_HISTORY_MESSAGES = 80
MAX_TOKENS_REPLY = 4000
GRADIO_SHARE = True
```

Что значит:

- `MAX_HISTORY_MESSAGES` — сколько последних сообщений пытаться отправлять модели;
- `MAX_TOKENS_REPLY` — сколько токенов оставить на ответ;
- `GRADIO_SHARE` — нужна ли публичная ссылка Gradio.

## Коротко о терминах

### Токен

Кусочек текста для модели.  
Это не буква и не слово. Слово может занимать один или несколько токенов.

### Контекст

Сколько токенов модель может видеть одновременно.  
Если разговор длиннее контекста, старые сообщения надо обрезать или сжимать.

### GGUF

Формат модели для `llama.cpp`.

### Квантование

Сжатие модели.  
Например, `Q5_K_M` — компромисс между размером, скоростью и качеством.

### Vision-проектор / mmproj

Дополнительный файл, который позволяет Qwen2.5-VL понимать изображения.

### VRAM

Видеопамять GPU.  
В ней работает модель. Если VRAM не хватает, генерация или запуск могут упасть.

### Stable Diffusion

Модель для генерации изображений по текстовому описанию.

### Gradio

Python-библиотека для быстрого веб-интерфейса.

## Повторный запуск

Если Colab перезапустился:

- локальные файлы в `/content` исчезнут;
- файлы на Google Drive останутся;
- ячейки снова проверят, что уже скачано и собрано;
- недостающее будет восстановлено или скачано заново.

Если модель была скачана только локально, её придётся скачать заново.

## Если что-то сломалось

### Проверить llama-server

```bash
curl http://127.0.0.1:8000/health
```

### Проверить прокси

```bash
curl http://127.0.0.1:8001/health
```

### Посмотреть лог llama-server

```bash
tail -100 /content/agent_local/logs/server.log
```

или, если используется Drive:

```bash
tail -100 /content/drive/MyDrive/agent/logs/server.log
```

### Посмотреть лог прокси

```bash
tail -100 /content/agent_local/logs/proxy.log
```

или:

```bash
tail -100 /content/drive/MyDrive/agent/logs/proxy.log
```

## Ограничения

- Colab может внезапно закончить GPU-сеанс.
- Бесплатная публичная ссылка Gradio временная.
- Большие модели требуют много места и видеопамяти.
- Генерация изображений может не влезть в VRAM при слишком большом размере картинки.
- Качество ботанических, медицинских, юридических и других точных ответов нужно проверять по источникам.
